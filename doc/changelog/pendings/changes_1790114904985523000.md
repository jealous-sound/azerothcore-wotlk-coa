### Changed

- CoA is part of the server core instead of a module. Its code builds from `src/server/coa/`, its tests live in
  `apps/coa-tests/` and its documentation in `docs/coa/`. It can no longer be disabled.
- CoA's configuration is `etc/modules/coa.conf` (previously `mod_ascension_compat.conf`) and its keys are named
  `CoA.*` (previously `AscensionCompat.*`), for example `CoA.LevelScaling`. CoA logs under `coa`,
  `coa.gameplay_test` and `coa.highrisk` instead of `module.ascension_compat`, `module.gameplay_test` and
  `module.highrisk`.
- CoA's historical SQL moved from `modules/mod-ascension-compat/` to `modules/mod-ascension/` unchanged, and the
  `item_template_ascension_compat` world table is renamed to `item_template_coa`.
- `dbimport` applies CoA's SQL whatever `Updates.AllowedModules` lists. As a module it was applied only when the value
  was `all` (the default) or named `mod-ascension-compat`.
- The CoA tests that read client DBCs use `env/dist/data/dbc`, the worldserver `DataDir/dbc` in the Docker setup, or
  `COA_DBC_DIR`.

### Upgrading

- Move the settings of `etc/modules/mod_ascension_compat.conf` into `coa.conf`, renaming `AscensionCompat.*` keys to
  `CoA.*`, then delete `mod_ascension_compat.conf`. Installing the server removes the old
  `mod_ascension_compat.conf.dist`; if you install another way, delete it by hand, or `acore.sh` copies it back.
- Rename environment overrides the same way: `AC_ASCENSION_COMPAT_<KEY>` becomes `AC_CO_A_<KEY>`.
- Add `Logger.coa=4,Console Server` to `worldserver.conf` and rename any `Logger.module.ascension_compat`,
  `Logger.module.gameplay_test` or `Logger.module.highrisk` line to its `Logger.coa` form. Without `Logger.coa`, CoA
  logs only errors.
- For a local (non-Docker) install, point `DataDir` in `worldserver.conf` at `env/dist/data` and keep the CoA
  client DBCs in `env/dist/data/dbc`.
- The table rename is applied by the normal database update on the next start or `dbimport` run.
- The worldserver logs an error at startup for each of these steps it finds undone.
