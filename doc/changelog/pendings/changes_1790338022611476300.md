### Fixed

- The Worldforged pickups of **Duskwood** are walked by hand in the map editor and written as the
  editor emitted them (`2026_09_25_48_worldforged_duskwood_pass_authored.sql`, the editing project's
  **58 saves** read in the order they were written, the last write to a row winning): **30 rows moved
  and/or turned**, **9 placements added** on guids the file allocates, **14 markers emptied**. Eight
  of the emptied markers are put down again elsewhere in the zone, so **six stand nowhere** - Emerald
  Shard, Ice Beard's Furled Finger, Grimtotem Totem, Holy Atal'ai Band, Wood Pile and Racing Goggles.
  The zone holds **48 pickups**, 39 of them authored in this pass.
- Every position and every rotation quaternion is the editor's own, digit for digit, and the
  orientation column is written as the yaw that quaternion represents. Where a save's own orientation
  column disagreed with the quaternion beside it - three rows: Catacomb Grave Dirt Pile (6940224),
  Emerald Shard (6940431) and Sharp Bone Necklace (6930015) - the quaternion is what is written, and
  the file says so at the row.
- The furthest rows: **Sizzling Potion** 150.67 yd, out of the Westfall-side listing it stood on and
  onto the Vul'Gol Ogre Mound spot the editor gave it, then **Axe of the Frostmane** 115.73,
  **Catacombs Relic Torch** 78.02, **Lantern of Endless Sorrow** 50.22, **Darkshire Grave** 33.56,

  **Defias Night Blade** 3.051 rad (174.8 deg).

  Woven Ceremonial Belt (254231, 6960030), Distant Wanderer's Pack (254384, 6960031), Lost

  creates **Crimson Blade** (254562, guid 6960032) in the zone.
- Two placements the zone's own sheet had missed are written and checked with the rest: **Sharp Bone
  Necklace** (90285, guid 6930015 at Raven Hill Cemetery, whose spawn row carries no script while its

- Nothing that is not this module's is touched: the same saves move the world's own **Bruiseweed**
  (guid 207693) and **Mageroyal** (guid 207604), and the file names both in its header as
  deliberately left alone.
- Every row was read back from the live database afterwards and matches the file exactly: **118
  assertions, none failing** - each moved row's position, rotation quaternion, the yaw that
  quaternion represents, its entry and its script, the placement on guid 6930015 and each of the nine
  guids the file allocates, and the absence of all fourteen removed guids. The file is idempotent -
  applied again it leaves the same rows - and the worldserver applies it on boot. The realm then
  reads **99,470 gameobjects**, **2,822 worldforged pickups** over **1,662 distinct ids** and
  **1,805 pickup templates**.
